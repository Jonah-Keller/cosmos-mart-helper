# Cosmos data mart — helper site

**Open the helper:** https://jonah-keller.github.io/cosmos-mart-helper/

Everything a data architect needs to deposit the mart: the interactive checklist (`index.html`), the
two-file SQL bundle (`bundle/`), the run order, the full step list, the column contract, and a prompt
for an AI assistant. No data, no results. The analysis and the rest of the project live in the private
repository `Jonah-Keller/cosmos-gbm-validation`; this site is a mirror of its Krishna-facing files,
regenerated by `deploy/publish_helper.sh` there.
